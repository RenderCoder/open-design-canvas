## Implementation plan

- Add a tolerant event parser for Codex JSONL.
- Recognize at least: agent_message, reasoning/summary, command execution, file changes, MCP tool calls, web searches, plan updates, errors.
- Normalize Figma MCP events into a small internal type: tool, status, args summary, result summary, timestamp/order.
- Use fixtures; do not require real Codex run for unit tests.
